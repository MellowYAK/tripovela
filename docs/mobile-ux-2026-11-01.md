# Mobile UX fixes — 2026-11-01

Global code changes apply to existing content and all visitors. No data migration, account restriction, or replacement database is involved.

- Feed pagination is explicit through More posts; scrolling no longer adds pages automatically, so the footer stays reachable.
- Navigation panels have bounded vertical scrolling. Wrapping controls retain gaps and padding. Avatars have fixed circular dimensions, including the composer.
- Search has a structured heading, search form, navigation shortcuts and spaced result cards.
- Account entry shows one mode at a time (sign in, register, recover). Registration asks for one public username; the initial display name uses it. Existing account names remain unchanged and profile editing remains available.
- The trip editor comes before preview/sharing actions. A compact save badge remains above it; the account backup prompt appears below nonempty content, not before writing starts.
- Formatting controls wrap correctly, preserve selection, and serialize nested lists correctly. Saved lists render as actual lists in the editor.
- Changed registration copy is translated in all 14 supported languages.
